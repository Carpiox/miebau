Política de privacidad

Cómo tratamos los datos que puedas facilitar al usar Miebau.

Última actualización: 2026.

Datos que se recogen

Miebau no requiere crear una cuenta para usar sus herramientas. Si utilizas un formulario de contacto o newsletter, podrías facilitar de forma voluntaria datos como tu nombre o correo electrónico.

Finalidad

Esos datos se utilizarán exclusivamente para responder a tu consulta o gestionar la suscripción cuando el servicio se conecte a una solución de envío.

Conservación y derechos

Puedes solicitar acceso, rectificación o eliminación de tus datos escribiendo a hola@miebau.es. No se cederán datos a terceros salvo obligación legal.

Seguridad

Se adoptarán medidas razonables para proteger los datos personales de acceso no autorizado, pérdida o alteración.
