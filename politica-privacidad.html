Política de privacidad

Cómo tratamos los datos que puedas facilitar al usar Miebau.

Última actualización: 2026.

Datos que se recogen

Miebau no requiere crear una cuenta para usar sus herramientas. Si solicitas un aviso de ponderaciones, recogemos de forma voluntaria tu correo electrónico y la universidad seleccionada.

Finalidad

Usamos esos datos exclusivamente para avisarte cuando se publiquen las ponderaciones 2026-2027 de esa universidad. No empleamos tu correo para comunicaciones comerciales, ofertas ni ninguna otra finalidad.

Conservación y derechos

Puedes solicitar acceso, rectificación o eliminación de tus datos escribiendo a hola@miebau.es. No se cederán datos a terceros salvo obligación legal.

Seguridad

Se adoptarán medidas razonables para proteger los datos personales de acceso no autorizado, pérdida o alteración.
